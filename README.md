
# BOSSONE.LK – Salon Marketplace Management System

## About the Project

BOSSONE.LK is a Salon Marketplace Management System developed as a group software development project at Lanka Nippon BizTech Institute (LNBTI).

The system aims to streamline salon-related marketplace operations by managing orders, inventory, quality control, accounting, deliveries and service management through a centralized platform.

## Technologies

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- NestJS
- TypeScript

### Database
- PostgreSQL
- Supabase
- Prisma ORM

### Version Control
- Git
- GitHub
